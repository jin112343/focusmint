# 1.3.5 (13) のアプリ内多言語対応

App Store掲載の39ロケールに対応するアプリ内翻訳を組み込んだ。各ロケール216メッセージ。英語・フランス語・スペイン語・ポルトガル語の地域差、簡体字・繁体字も含む。

別チェックアウトに保存されていた既存の翻訳を読み取り専用で参照し、現在の画面・仕様に合うキーだけを採用した。呼吸ガイド、お問い合わせ、画像分類、カスタム画像の混合設定などを追加・修正した。元のチェックアウトは変更していない。

- `AppLocalizations.supportedLocales` をアプリ本体に接続。端末の言語へ自動追従する。
- 台湾・香港・マカオの中国語は繁体字へ、Norwegian `no` はBokmål `nb` へ解決する。
- iOSの言語宣言と写真の利用目的文、Androidのアプリ言語設定にも39ロケールを登録。
- 問い合わせの自動受付、送信状態、日付・時刻をローカライズ。吹き出しと余白は文字方向に追従する。
- 小さい画面で長い見出しや結果がはみ出さないよう折り返し・スクロールに対応。
- 得点説明は「正しい選択1回につき最大6ポイント」へ修正。アプリの効果を保証する説明は、セルフケアの練習であることが分かる表現へ見直した。

`tool/check_localizations.py` で39ロケールのメッセージ数、プレースホルダー、長文の英語フォールバック、日本語の残存、両OSの言語登録を照合する。ブランド名や単位など、言語間で同じ文字列を使う場合もある。

Flutterの表示テストでは、全39ロケールを320×568で検証。ホーム、導入説明、設定、履歴、画像管理と未保存表示、カスタム画像設定、問い合わせとキーボード表示、トレーニング、結果、呼吸ガイドを含む。

ネイティブの実行確認は日本語・ドイツ語・アラビア語・繁体字中国語・ヒンディー語を代表として行う。各言語の専門翻訳者による校閲や、全39ロケールの全端末実機検証を行ったという意味ではない。実行・提出結果は[リリース記録](../1.3.5/release.md)を参照。
